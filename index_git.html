Revisão de versionamento

É um sistema de versões.

Git é um sistema de controle de versões.

GitHub é uma plataforma de hospedagem de repositórios.

Analogia

  • Git: sistema de save.
  • Commit: ponto salvo.
  • GitHub: cópia do histórico em um servidor remoto.

Comandos Git

  • git init : cria o repositório Git local.
  • git status : verifica o status do repositório.
  • git add : adiciona arquivos para o próximo commit.
  • git commit : confirma as alterações.
  • git log : mostra o histórico de alterações.
  • git branch : gerencia linhas de desenvolvimento.

Criando um repositório

Preciso criar meu repositório no GitHub para iniciar as configurações de publicação do projeto.

Por que não criar o README.md?

Como nosso projeto já possui um histórico, manter o repositório remoto vazio simplifica a conexão e evita históricos diferentes.

Configurando o repositório remoto

  • git remote add origin : adiciona o repositório remoto.
  • git remote -v : visualiza a conexão com o repositório remoto.

O que é origin?

origin é um nome convencional dado ao repositório remoto.

git push envia a branch main usando o remoto origin e configura o acompanhamento entre as branches local e remota.

Os próximos envios podem ser feitos com git push .

git pull obtém alterações que ainda não estão no seu computador.

Fluxo completo diário

  1. git pull : início dos trabalhos.
  2. Edite o projeto e confira as alterações com git status .
  3. Prepare as alterações com git add . .
  4. Registre as alterações com git commit -m "Edição do projeto" .
  5. Envie as alterações com git push .
